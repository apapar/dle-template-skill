# RSS Informer

*DLE documentation topic #34*

This module is intended for publishing news from your partners' websites from other websites in a specific block on your website. By going to the admin panel to add a new informer, you define the following parameters for it:

**RSS informer name** \- in this field you specify the name of the informer; the name may be unique or the same as for other informers. If the name is the same, informers are displayed in rotation mode.

**RSS informer description** \- a short description of this informer for your own reference

**Category** \- you can specify the category in which this informer should be shown, or make it available in all categories

**URL for the RSS informer** \- here you specify the path to the RSS source from which the news will be taken

**Template for the informer** \- specify the template that will be loaded to display the formatted information in this block. For exampleinformer.tpl**

**Number of news items in the block** \- specify the number of news items that should be shown in this block

**Number of characters in the title** \- specify the maximum number of characters in the title; if this limit is exceeded, the title will be truncated automatically. You can set the value to 0, in which case the title will be imported in full

**Number of characters in the news text** \- specify the maximum number of characters in the news item; if this limit is exceeded, the news item will be truncated automatically. You can set the value to 0, in which case the news item will be imported in full
