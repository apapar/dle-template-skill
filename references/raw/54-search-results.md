# Search Results

*DLE documentation topic #54*

The output of this section is configured in the **searchresult.tpl** file. This section configures the templates responsible for displaying news found as a result of a search:

`[searchposts]`
text
`[/searchposts]` |  Outputs found results for news items
---|---
`[searchcomments]`
text
`[/searchcomments]` |  Outputs found results for comments
`[fullresult]`
text
`[/fullresult]` |  Outputs results as articles
`[shortresult]`
text
`[/shortresult]` |  Outputs results as titles
