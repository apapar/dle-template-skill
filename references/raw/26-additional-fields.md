# Additional Fields

*DLE documentation topic #26*

In this section, you can create and edit additional fields. Additional fields make it easier to add information to the website. By default, there are only two fields: short description and full description of the news item. However, you can create other fields for entering information, for example a source link or a program link, and once you configure the output of the field in templates, the need for constant manual formatting of frequently repeated information disappears.

When adding a new field, you enter its name (in Latin letters), field description (displayed next to the input field), category to which this field belongs (you can choose whether the field is entered for all categories or belongs only to one category; you can also selectively assign categories to which this field will belong by selecting the required categories in the list while holding down the Ctrl key), field type (you can choose three field types: a single line, large text, or a drop-down list of values), and you can also assign a default value for the field. If you want the field to be optional when entering information, tick the corresponding checkbox; otherwise, the news item will not be added if this field is not filled in.
