# Category Configuration

*DLE documentation topic #25*

In this section, you can create and edit categories. When creating a new category, you specify its name, alternative category name, icon path, choose whether the new category is a subcategory and where, and also optionally specify which template will be used when displaying articles from this category and when viewing this category itself. The icon is an optional parameter. Attention: the alternative name is specified using Latin letters only and is used for displaying all news from this category. For example, if you create a category with the name "Software" and the alternative name "soft", then to view all news from this category with SEF URLs enabled, enter http://website.com/soft/ in the browser address bar, and with SEF URLs disabled enter http://website.com/?do=cat&category=soft
