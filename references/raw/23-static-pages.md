# Static Pages

*DLE documentation topic #23*

In addition to writing dynamically changing news, the engine also allows you to create static pages that are not expected to change frequently. To create a static page, select **"Create new page" then enter the page name using Latin letters only because it will be passed in the website URL for viewing, then enter the page description, which is information only for you, and finally create the page template itself, where HTML is allowed. After creating the page, you will be able to view, modify, or delete it.

The address of a static page with SEF URLs enabled looks like this: `https://website.com/page-name.html`

The address of a static page without SEF URLs looks like this: `https://website.com/index.php?do=static&page=page-name`
