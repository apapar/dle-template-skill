# Personal Messages

*DLE documentation topic #12*

All users authorized on the website can send personal messages to each other. These messages can later be viewed, deleted, and replied to. A specific template is used to display them. When editing this template, be extremely careful so as not to break the functionality of this module. Editing this template does not require PHP knowledge, but you must understand HTML and its specifics. In other words, do not modify information input fields from forms unless there is a real need to do so.
