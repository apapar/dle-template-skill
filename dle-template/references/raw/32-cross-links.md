# Cross Links

*DLE documentation topic #32*

This module is intended for fast and convenient creation of internal cross-linking across the website by keywords. In this section, you specify a keyword and a URL; if this keyword is found on your page, it will be replaced with a hyperlink. Unlike the "word filter" module, which is also present in the script, this module searches for keywords across the entire page, including all content (news, comments, templates, third-party modules, and so on), and not only in news and comments. Any addition or modification of keywords in this section is applied instantly on all pages of your website without requiring publication rebuilding. The module also supports specifying word inflections; for example, you can set the keyword "Ivan(ov|ova|ovu)" and the link will be applied to the words Ivanov, Ivanova, Ivanovu, and so on. Keyword searching is performed only by whole words, not by all occurrences inside the text.
