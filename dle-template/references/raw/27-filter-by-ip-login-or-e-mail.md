# Filter by IP, Login, or E-Mail

*DLE documentation topic #27*

You can use this section to block specific IP addresses or block specific email addresses and usernames during registration. If you enter an IP address, access to the website from that IP or subnet is blocked completely, not only for registration.
 
**Note:** you can use the asterisk * in the filter as a wildcard in the username, IP address, or email address (for example: 127.0.*.*, *@mail.ru, username*).
