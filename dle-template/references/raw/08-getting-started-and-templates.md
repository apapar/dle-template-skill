# Getting Started and Templates

*DLE documentation topic #8*

One of the engine's features is that any existing design can be connected to it without any limitations. The engine supports working with several templates simultaneously. All templates are located in the `/templates/` folder. Each subfolder in this folder is a separate website layout. Therefore, if you downloaded a new template for the engine, simply copy it to the `/templates/` folder and enable its use in the control panel in the script settings section. You can also allow your website visitors to switch the design themselves so they can choose how their favorite website looks. Additionally, you can set the number of news items displayed per page by opening the script settings and configuring the appropriate parameter.

In template files you can use regular HTML text, or you can use special tags to insert specific features. You can read more about the supported tags below in this guide in the **Templates** section.
