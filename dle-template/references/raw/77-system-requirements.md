# System Requirements

*DLE documentation topic #77*

### Minimum system requirements for DataLife Engine

For DataLife Engine to function fully, the following software must be installed on the server:

  * Nginx or Apache
  * PHP 8.0 and above
  * MySQL 5.6 and above or MariaDB 10.0 and above

Required modules for PHP interpreter:

  * Installed PHP library **zlib**
  * Installed PHP library **xml**
  * Installed PHP library **gd2**
  * Installed PHP library **curl**
  * Installed PHP library **mbstring**
  * Installed PHP library **fileinfo**
  * Installed PHP library **exif**
  * Installed PHP library **intl**

Minimum RAM size is **16 Megabytes**.
