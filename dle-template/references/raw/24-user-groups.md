# User Groups

*DLE documentation topic #24*

In this section, you can add and edit new and existing user groups. When adding a new user group, you define its available categories and permissions on the website.

**Available sections:** Sections that the selected group has access to

**Trusted sections:** If you allow the group to publish news on the website without prior moderation or allow it to edit news created by other users, then in this setting you specify which sections you trust for the group. Editing news in sections not specified here will be prohibited. A visitor can always add news to the sections available to them, but if one of the categories is outside the trusted sections, the entire news item will not be published without prior moderation. Categories where posting without moderation is not allowed are highlighted in red when adding news.

**Allow access to the admin panel:** this option allows the user to access the admin panel, but does not give access to all of its functions. Access is granted only for adding or editing news from the admin panel. Only Administrators have access to all functions.

**Hide only full news from inaccessible sections:** If a user is denied access to a section, you can choose either to prohibit all access or to prohibit only viewing full news. If you prohibit only viewing full news, you will significantly reduce server load and the time required to fetch news.

**Allow adding news:** You can prohibit or allow users to add news to the website.

**Publish news without moderation:** Permission to publish news in trusted sections without prior moderation

**Allow pinning news:** Permission for users to pin news on the website

**Edit own news:** Permission for users to edit their own news after it has already been published on the website

**Edit all news:** Permission for users to edit any news in trusted sections.

**Allow adding comments:** Permission for users to leave comments on the website

**Edit own comments:** Permission for users to edit their own comments

**Delete own comments:** Permission for users to delete their own comments

**Edit all comments:** Permission for users to edit any comments

**Delete all comments:** Permission for users to delete any comments on the website

**View hidden text:** Permission for users to view the contents of the tag that contains hidden text

**Allow using PM:** Permission for users to use personal messages on the website

**Allow file downloads:** Permission for users to download files uploaded to the server

**Use feedback:** Permission for users to use website feedback

**Use website search:** Permission for users to use website search

**Temporary placement in the group:** You can temporarily place users in this group. When moving a user into this group, specify until what date they should remain in it. After that period ends, the user will be moved automatically to the primary group.

**Primary group after the limit ends:** Specify the user's primary group to which they will be moved after the time spent in the temporary group expires.
