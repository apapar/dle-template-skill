# Grammar Error Reporting System

*DLE documentation topic #15*

The DataLife Engine script includes a system for reporting grammar and other errors on the website. A visitor can select any text in the browser, press `Ctrl+Enter`, and will be prompted to send a notification to the website administration about an error in the selected text. At the same time, the user can select any text on any page of your website.

We recommend placing a notification block about this feature in some visible area of your website for your visitors.

Grammar error reports are managed in the admin panel in the reports management section. The notification itself is sent from the website using AJAX without reloading the page and does not cause inconvenience to users.
